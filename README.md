# Games

Home page for games.shauna.digital. Each game lives in its own repository and Vercel project, and is mounted under a path here by a rewrite in `vercel.json`.

## Add a game

1. Deploy the game as its own Vercel project, built with relative asset paths.
2. Add a redirect and a rewrite for its path in `vercel.json`.
3. Add a card for it in `index.html`.
